# 參考角練習 PWA

給高中二年級的三角函數參考角練習。每題會從 0° 到 360° 隨機取一個整數角，並排除 0°、90°、180°、270°、360° 等軸上角；連續答對 20 題即可通關。

## 使用方式

以本機伺服器或靜態網站主機開啟 `index.html`，即可安裝為 PWA 使用。完成闖關頁可下載 CSV 成績紀錄。

## 上傳至 Google 試算表（專用試算表）

1. 在 [Google Apps Script](https://script.google.com) **另外建立一個新專案**，貼上 `gas/Code.gs`；請勿使用原本加減闖關的 Script 專案。
2. 執行 `setup()` 一次並授權；執行紀錄會顯示新建試算表的網址。
3. 部署為「網頁應用程式」，存取權設為可存取的使用者範圍，複製部署後的 `/exec` 網址。
4. 在 PWA 首頁開啟「紀錄與試算表設定」，貼上網址並儲存。

這個 Script 專案在首次執行 `setup()` 時，會自動建立一份獨立的「參考角練習紀錄」Google 試算表。每次通關會寫入：完成時間、作答秒數、答錯次數、最高連勝與通關狀態。
